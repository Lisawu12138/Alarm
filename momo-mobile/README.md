# Momo · Project Alarm 手机原型

一个与好友共享早晨仪式、共同照顾宠物 Momo 的 Expo / React Native 可点击原型。中文默认，可在设置中切换英文。

## 运行

使用 Node.js 24 LTS 和 pnpm 10。

```sh
cd momo-mobile
pnpm install --frozen-lockfile
pnpm start
```

在支持 Expo SDK 58 的 Expo Go 中扫码查看手机界面；浏览器预览运行 `pnpm web`。`pnpm typecheck` 检查 TypeScript。浏览器预览已在 Replit 中确认可显示，尚未完成 iPhone / Android 真机验证。

## 演示内容

- 五个主页面：小组、闹钟、语音、照顾、设置。
- 闹钟时间、重复日、好友语音选择、音量和 15–60 秒挑战设置。
- 模拟响铃后长按按钮模拟轻摇：有效进度按时间增加，暂停短暂缓冲后回退；紧急停止立即跳过、无积分。
- 挑战首次完成获得 10 个人积分；10 积分购买一份食物，再主动喂养小组宠物。待同步不会被当成成功，当天已喂食不重复消耗。
- 好友录音、发送、送达和播放状态均为本地模拟。
- 设置支持昵称、三种预设头像、默认铃声、音量、中英文、版本和关于。
- 本地数据保存在 AsyncStorage；演示选项可重置本地数据。

## 原型边界

没有后端、真实好友账号、收费、语音克隆或 LLM 服务。音频、录音、提醒和摇动为演示，不会真正录音或播放声音，不保证锁屏/后台/系统闹钟能力。音量仅为应用内演示值，不等于系统音量。请勿把本原型当作实际起床闹钟。

## 仓库组织

本目录是从 Replit 手机原型导出的独立运行版本。源码和 Momo SVG 角色保留；为避免依赖 Replit 的父级工作区，移除了未使用的共享 API 客户端引用，并将工作区依赖别名换为普通版本。未包含后端、Design canvas 工具、密钥、用户本地数据或缓存。
